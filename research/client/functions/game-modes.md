## Overview

- Modes are `DEF_GAMEMODE_*` in Game.h:104-126, values -2..21 (verified). `ChangeGameMode` sets the mode and resets the per-mode counter; `UpdateScreen` (Game.cpp:1106) switches to one `UpdateScreen_On<Mode>` per frame.
- Each `UpdateScreen_On*` both handles input for that screen (mouse rectangles, Enter/Esc) and draws it; there is no separate input pass outside `OnGame`.
- Login, account creation, character select/create and the log-server exchange are documented in `..\..\servers\client-log-protocol.md`; this file only maps the functions. Multiple `#if` bodies exist for several screens (e.g. three `UpdateScreen_OnMainMenu`); in the English build the `#else` body (shared with Korea/Japan) is the one compiled: UpdateScreen_OnMainMenu runs Game.cpp:3391-3538, UpdateScreen_OnSelectCharacter runs 21806-22084 (see `..\build-config.md`).
- `UpdateScreen_OnLoading` is in `config-loading.md` because it is the bulk sprite loader. `UpdateScreen_OnGame` is the gameplay frame, described step by step in `..\rendering\frame-pipeline.md`.
- `CCharInfo` (CharInfo.cpp) is the per-slot record shown on character select.
