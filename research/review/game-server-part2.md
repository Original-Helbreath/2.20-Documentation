# Review: game-server docs, part 2 (npc, map-movement, guild-party, crusade-quests, chat-gm, mechanics, data-structures)

Reviewer: read-only verification against `.claude/scratch/srv220/` (v2.20 HGserver). Nothing in the docs was edited.
Paths below: `Game.cpp:N` = `.claude/scratch/srv220/Game.cpp` line N. Status words: verified / failed / unverified.

## Method and encoding note

- Brief said Korean comments are cp949. Measured: `Game.cpp`, `Map.cpp`, `Client.cpp`, `Misc.cpp`, `Game.h`, `GlobalDef.h` decode cleanly as UTF-8 (no BOM); only `Npc.cfg` is cp949. Decoding the sources as cp949 yields mojibake. The docs' Korean quotes are correct.
- Active build switches (GlobalDef.h, measured): `DEF_CHINESE` (line 16) on, which turns on `DEF_CHINESEGUILDLIMIT`, `DEF_NPCITEM`, `DEF_DBGAMESERVER`, `DEF_LOGTIME`, `DEF_DEFENCEHACKING` (lines 65-77); `DEF_V219` on (24). Off (commented): `DEF_TESTSERVER`, `DEF_TAIWAN`/`DEF_TAIWANLOG`, `DEF_GUILDWARMODE`, `DEF_CHECKUSERNPCNUM`, `DEF_WINTER`, `NO_MSGSPEEDCHECK`.
- Mechanical checks, run by script over all 220 entries: file:line range (def line and closing brace), callers (name scan over every function body, comments and strings stripped), callees, `MSGID_`/`DEF_MSGTYPE_`/`DEF_NOTIFY_` tokens, quoted cfg names.
  - Ranges: 220/220 match exactly (7 functions defeated my brace matcher; ends checked by hand: 16717, 11225, 36189, 36719, 44003, 46338, 46599 all close with `}`).
  - Callers/callees/message tokens: match the name-scan result except the overload merges listed below. The doc's own method (name scan) is what produced them; they are faithful to it.
  - Missing functions: 454 col-0 `Class::fn` definitions in Game.cpp/Map.cpp/Client.cpp/Npc.cpp/Misc.cpp etc. were regex-listed; 0 are absent from `functions/*.md`. `CrusadeCore.cpp` is entirely commented out (not a gap).
- Semantic read of the function body: about 95 of 220 entries. The rest are mechanical-only (listed under "Not verified").
