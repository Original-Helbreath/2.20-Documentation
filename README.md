# 2.20-Documentation

Analysis and documentation of Helbreath 2.20: the client, game server, gate and both log servers.

## Contents

- `research/` - the analysis. Start at `research/systems.md` (what each system is meant to do and does now),
  `research/overlap.md` (how the five programs connect and what they share) and `research/issues.md` (defects; mirrored on the
  project board). `research/sources.md` records where every source and file came from.

The original downloads themselves are kept in [Downloads-Archive](https://github.com/Original-Helbreath/Downloads-Archive).

## Branches

| Branch | Purpose |
|---|---|
| `development` | Integration branch. Work happens in feature branches, which merge into `development`. |
| `stable` | Default branch. `development` is merged here once it is stable. |

There is no `original` branch: this documentation is our own work, not material found elsewhere.

## Project

Part of [Original Helbreath](https://github.com/Original-Helbreath): keeping the original 1999-2005 Siementech Helbreath alive.
Repos are named `<version>-<Part>`; other versions follow the same pattern.
Issues are tracked on the [project board](https://github.com/orgs/Original-Helbreath/projects/1). The analysis behind everything is in
[2.20-Documentation](https://github.com/Original-Helbreath/2.20-Documentation).
